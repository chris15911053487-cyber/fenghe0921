数据对不上时，按这个顺序查

  1. 先跑校验，从小号看起。C01–C20 按计算顺序排列，越靠前越接近数据源头。第一个不通过的校验，通常就是问题的源头；先修它，后面的差异往往跟着消失。
  2. 按症状找入口。已经知道是哪类数字不对时，用下表直接跳到对应的校验。
  3. 锁定到具体物料或订单后，用 T01 / T02 追溯。T01 列出一个物料本期每条出入库的单价和 PriceMemo（每次改写都会追加“从哪个过程哪一步写入”）；T02 按“订单头 → 领料 → 费用 → 成本结果 → 完工入库”展开一张订单。
  4. 在“字段影响”里看上游。找到出错的字段后，看它的上游字段，逐个回查；需要评估影响时看下游。

全部查询只读，不改数据。原文件在仓库 checks/MTC_COST_CHECKS.sql，把每段开头的 '2026-08' 改成要查的账期后执行。
