依次执行：从 B1 同步费用池与归集参数 → 快照 → 计算前检查（有阻断项就停止）→ 迭代计算 → 定稿 → 计算后校验 → 新旧比对 → 发出商品 / 应付暂估 / 凭证 → 收尾。只写 MTC_CA_* 表，不改 B1 单据，不过账。

模拟场景

模拟计算（在“发起计算”里类型选“模拟”）在快照之后按场景假设调整：采购价、费用池、单位工时的百分比；结果单独保存，不影响正式结果。
