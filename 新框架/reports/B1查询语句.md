# 成本报表：B1 查询管理器语句

> 由 `新框架/tools/gen_rpt.py` 按 `新框架/reports/rpt_defs.json` 生成，不要手改。过程定义在 `新框架/sql/21_reports.sql`（用户 2026-10-30）。

用法：B1 → 工具 → 查询 → 查询管理器 → 新建，把语句整段粘贴进去，保存到分类“成本报表（新）”（或运行 `python3 新框架/tools/sl_import_queries.py` 一次登记全部 24 条）。
执行时 B1 依次弹出参数框：**留空 = 全部**；多个值用英文逗号；物料、订单号、业务伙伴按开头匹配，前面加 `=` 精确匹配（如 `=A1`）。
账期留空 = 最近一个已计算账期。所有报表都取该账期“生成凭单所用运行”，没有生成凭单时取“最近一次成功正式运行”，与执行台“成本报表”页完全一致（看 R00）。

`/* SELECT FROM … */` 注释行是给 B1 参数框认字段用的（弹出选择列表）；HANA 版 B1 是否生效部署时验证，不生效也可以直接手填。

## R00 成本报表运行状态

各账期的报表取的是哪次运行（已生成凭单取凭单所用运行，否则取最近一次成功正式运行；承接账期及以前取旧框架回填的历史运行）、什么时候算的、凭单批号。所有报表都按这个规则取数，与执行台顶栏所选的运行无关。

| # | 参数 | 填法 |
|---|---|---|
| [%0] | 起始账期 `FcFrom` | 空 = 最近 12 个账期 |
| [%1] | 截止账期 `FcTo` | 空 = 同起始账期 |

```sql
/* SELECT FROM "OFPR" T0 WHERE T0."Code" = '[%0]' */
/* SELECT FROM "OFPR" T1 WHERE T1."Code" = '[%1]' */
CALL "MTC_CA_RPT_00_RUN"('[%0]', '[%1]');
```

## R01 产品成本计算单

每张订单：期初在产品 + 本期投入 + 本级分摊 = 完工转出 + 关单差异 + 期末在产品（四项要素），“勾稽差额”应为 0。完工转出合计 = R02 = R03 生产入库；期末在产品 = R09 在产品业务端。 承接账期及以前取旧框架回填的历史运行，料工费按旧框架完工比例拆分（估算）。

| # | 参数 | 填法 |
|---|---|---|
| [%0] | 起始账期 `FcFrom` | 空 = 最近一个已计算账期 |
| [%1] | 截止账期 `FcTo` | 空 = 同起始账期 |
| [%2] | 订单类型 `WorType` | 空 = 全部；10 = 10 生产计划单；20 = 20 包装计划单；30 = 30 返工计划单；40 = 40 生产试打；50 = 50 委外工单；10,20,30,40 = 生产类（10–40） |
| [%3] | 订单号 Num `OrderNum` | 开头匹配，多个用逗号；=开头精确匹配 |
| [%4] | 产品 `Item` | 开头匹配，多个用逗号；=开头精确匹配 |
| [%5] | 产品物料组 `ItemGrp` | 物料组代码，多个用逗号 |
| [%6] | 订单范围 `Scope` | 空 = 全部；1 = 本期有完工；2 = 本期按关单处理；3 = 期末有在产品 |
| [%7] | 显示方式 `STYPE` | 0 = 按订单；1 = 订单 × 材料 |

```sql

/* SELECT FROM "OFPR" T1 WHERE T1."Code" = '[%1]' */
```

## R02 完工产品成本汇总

每个产品每个账期的完工数量、四项成本、单位成本和构成 %。成本是还原后的：完工成本·制造 = 本级分摊·制造 + 领料带入·制造（材料和半成品里含的制造），人工同理，不加条件时这两项的本级分摊合计 = R06 已分配。完工成本·委外 = 本级分摊·委外（订单自己的加工费结转，不走费用池，委外工单上的合计 = R07 完工转出·加工费）+ 领料带入·委外。“本级分摊·材料”= 完工成本·合计减去本级制造、人工、委外，即领用的材料和半成品全额（半成品里含的料工费都算材料，同 R22 本级口径），本级四项合计 = 完工成本·合计。“入库单价”= 完工入库单据行的金额 ÷ 数量，用来核对单位成本·合计，正常只差分位。 承接账期及以前取旧框架回填的历史运行，料工费按旧框架完工比例拆分（估算）。

## R23 产品销售毛利走势

物料每个月的收入、成本和毛利，月份做列看趋势。业务端，和凭证过账无关。暂估收入取交货行金额，暂估成本取成本单价。“随时看”：当月 = 当月发票（减贷项）+ 当月交货中至今未开票的部分，以前月份的数会随后续开票变化。“月结固定”（给管理层）：当月 = 当月发票 + 期末暂估 − 期初暂估，只列已结账账期，这个月的数不再变，开票差价落在开票月。服务、直接开票、纯金额贷项放在“(未归属产品)”一行，只有收入。默认不含样品。“缺成本单价行数”不为 0 表示成本偏低；“缺销售单价行数”是交货行金额为 0 的行；“结账后补单行数”不为 0 表示有人往已结账期补了单。

| # | 参数 | 填法 |
|---|---|---|
| [%0] | 起始账期 `FcFrom` | 空 = 全部月份 |
| [%1] | 截止账期 `FcTo` | 空 = 到本月 |
| [%2] | 物料 `Item` | 开头匹配，多个用逗号；=开头精确匹配 |
