# 成本报表：B1 查询管理器语句

> 由 `新框架/tools/gen_rpt.py` 按 `新框架/reports/rpt_defs.json` 生成，不要手改。过程定义在 `新框架/sql/21_reports.sql`（用户 2026-10-30）。

用法：B1 → 工具 → 查询 → 查询管理器 → 新建，把语句整段粘贴进去，保存到分类“成本报表（新）”（或运行 `python3 新框架/tools/sl_import_queries.py` 一次登记全部 19 条）。
执行时 B1 依次弹出参数框：**留空 = 全部**；多个值用英文逗号；物料、订单号、业务伙伴按开头匹配，前面加 `=` 精确匹配（如 `=A1`）。
账期留空 = 最近一个已计算账期。所有报表都取该账期“生成凭单所用运行”，没有生成凭单时取“最近一次成功正式运行”，与执行台“成本报表”页完全一致（看 R00）。

`/* SELECT FROM … */` 注释行是给 B1 参数框认字段用的（弹出选择列表）；HANA 版 B1 是否生效部署时验证，不生效也可以直接手填。

## R00 成本报表运行状态

各账期的报表取的是哪次运行（已生成凭单取凭单所用运行，否则取最近一次成功正式运行）、什么时候算的、凭单批号。所有报表都按这个规则取数，与执行台顶栏所选的运行无关。

| # | 参数 | 填法 |
|---|---|---|
| [%0] | 起始账期 `FcFrom` | 空 = 最近 12 个账期 |
| [%1] | 截止账期 `FcTo` | 空 = 同起始账期 |

```sql
/* SELECT FROM "OFPR" T0 WHERE T0."Code" = '[%0]' */
/* SELECT FROM "OFPR" T1 WHERE T1."Code" = '[%1]' */
CALL "MTC_CA_RPT_00_RUN"('[%0]', '[%1]');
```

## R01 产品成本计算单

每张订单：期初在产品 + 本期投入 + 本级分摊 = 完工转出 + 关单差异 + 期末在产品（四项要素），“勾稽差额”应为 0。完工转出合计 = R02 = R03 生产入库；期末在产品 = R09 在产品业务端。

| # | 参数 | 填法 |
|---|---|---|
| [%0] | 起始账期 `FcFrom` | 空 = 最近一个已计算账期 |
| [%1] | 截止账期 `FcTo` | 空 = 同起始账期 |
| [%2] | 订单类型 `WorType` | 空 = 全部；10 = 10 生产计划单；20 = 20 包装计划单；30 = 30 返工计划单；40 = 40 生产试打；50 = 50 委外工单；10,20,30,40 = 生产类（10–40） |
| [%3] | 订单号 Num `OrderNum` | 开头匹配，多个用逗号；=开头精确匹配 |
| [%4] | 产品 `Item` | 开头匹配，多个用逗号；=开头精确匹配 |
| [%5] | 产品物料组 `ItemGrp` | 物料组代码，多个用逗号 |
| [%6] | 订单范围 `Scope` | 空 = 全部；1 = 本期有完工；2 = 本期按关单处理；3 = 期末有在产品 |
| [%7] | 显示方式 `STYPE` | 0 = 按订单；1 = 订单 × 材料 |

