# SAP B1 维护数据：成本核算参数与费用池

用途：把成本核算新框架（MTC_CA）的计算参数和费用池录入 SAP B1。新框架每次计算前会从这些表读取配置（步骤 P05）。
表结构说明见 `B1自定义表_费用配置.md`。下面的取值是新框架当前的默认值（2026-10-14 整理）。

## 一、录入前提

在 B1 里已经建好以下用户定义表，并注册了 UDO（类型“主数据”，勾选“查找”“默认表单”“日志”）：

| UDO | 主表 | 子表 |
|---|---|---|
| `MTC_CA_EXPSET` 费用归集参数 | `@MTC_CA_EXPSET` | `@MTC_CA_EXPSET1` |
| `MTC_CA_POOL` 费用池 | `@MTC_CA_POOL` | `@MTC_CA_POOL1`、`@MTC_CA_POOL2` |

如果记录已经存在，就核对取值，不要重复新建（同一个代码只能有一条）。

## 二、费用归集参数 `MTC_CA_EXPSET`

录入方法：打开 UDO `MTC_CA_EXPSET` 的默认表单，每个参数新建一条记录：

- **代码（Code）**、**名称（Name）**：按下表照抄，代码区分大小写。
- 子表**只填一行**：起始账期 `FromFc` 和截止账期 `ToFc` 都**留空**（表示所有账期），**取值** `Value` 按下表填写。
- 列表型的取值用英文逗号分隔，前后都不加逗号。“空”字照抄，它表示没有凭证代码的手工凭证。
- 数字型的取值只能填数字，不要带单位或 %。

### 费用归集

| # | 代码 Code | 名称 Name | 取值 Value |

## 三、费用池 `MTC_CA_POOL`

打开 UDO `MTC_CA_POOL` 的默认表单，新建两条记录：

### 表头

| 代码 Code | 名称 Name | 默认池 IsDefault | 关单差异池 IsCloseDif | 说明 Descr |
|---|---|---|---|---|
| `MFG` | 制造车间 | `Y` | `Y` | 成本中心不是 P017 的费用；关单差异也进这个池 |
| `PKG` | 包装车间 | `N` | `N` | 成本中心 P017 的费用 |

默认池、关单差异池都必须**正好一个**池填 `Y`。

### 成本中心（子表 `MTC_CA_POOL1`）

| 池 | 成本中心 OcrCode | 起始账期 FromFc | 截止账期 ToFc | 说明 Descr |
|---|---|---|---|---|
| `MFG` | （不填，默认池） | | | |
| `PKG` | `P017` | 空 | 空 | 成本中心主数据 U_CalType = P017 的成本中心都进包装车间 |

### 分摊范围（子表 `MTC_CA_POOL2`）

| 池 | 匹配方式 MatchBy | 匹配值 MatchVal | 订单类型 WorTypes | 起始账期 FromFc | 截止账期 ToFc | 说明 Descr |
|---|---|---|---|---|---|---|
| `MFG` | `GRPTYPE` | `B` | `10,20,30,40` | 空 | 空 | 车间类别 B |
| `MFG` | `GRPTYPE` | `C` | `10,20,30,40` | 空 | 空 | 车间类别 C |
| `PKG` | `GRPTYPE` | `A` | `10,20,30,40` | 空 | 空 | 车间类别 A 包装 |

## 四、以后要改参数时

- 不要直接改原来那一行的取值，否则重算已经算过的账期时会用上新值。
- 正确做法：把原来那行的**截止账期**填成上一期（如 `2026-10`），再新加一行，**起始账期**填新账期（如 `2026-11`），在新行填新取值。
- 同一个参数，起始账期不能重复。

## 五、录完以后

在成本执行台点“只做检查”：
- 步骤 P05 显示“已从 B1 同步 …”。
- 计算前检查 PRE-18 通过。

两项都满足即可。如果 P05 显示“B1 配置有误”，按提示的原因修正（常见原因：代码写错、同一参数起始账期重复、数字型参数的取值不是数字、默认池或关单差异池不是正好一个）。
