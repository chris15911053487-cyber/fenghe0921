# 关于本手册

本手册面向负责月度成本结账的成本会计、总账会计和财务主管，按结账的先后顺序说明每一步怎么操作、做到什么程度算完成、出了问题看哪里。本手册在成本执行台左侧菜单“使用手册”中随时可以打开，内容随系统版本更新。

每月结账时可配合《成本月结清单》逐项勾选。核算口径见《成本核算规则说明》，校验编号的完整说明见《校验与异常处理手册》。

> **关于截图**：本手册的截图经过脱敏处理，物料、业务伙伴、人员名称和金额都不是真实数据，只用于说明界面。

# 第 1 章 开始之前

## 1.1 权限

成本执行台使用 B1 账号登录。权限在 B1 用户主数据中设置，分为三级，高级别包含低级别的全部权限。

| 权限 | 可以做什么 | 建议给谁 |
|---|---|---|
| 查看 | 查看运行结果、校验、对账和报表 | 财务人员、管理层 |
| 操作 | 另可执行只做检查、模拟计算、维护模拟场景，生成期初价、工时单据和库存重估单 | 成本会计 |
| 管理 | 另可执行正式计算、期初承接、生成和撤销凭单、确认校验阻断项 | 成本主管、财务主管 |

权限字段为空的账号不能登录。

## 1.2 登录

1. 在浏览器打开系统管理员提供的成本执行台地址。
2. 公司有多个时，先选择公司（账套）。
3. 输入 B1 用户代码和密码，点“登录”。

![登录页面](shot:login)

要切换公司，需要退出后重新登录。

## 1.3 界面

![成本执行台主界面](shot:overview)

- ① **运行切换**：一次运行是对某个账期的一次计算或检查。点开可看运行记录，选中哪次，左侧菜单各页就显示哪次的结果。
- ② **左侧菜单**：按用途分组，点分组名可以折叠。
- ③ **发起计算**：进入发起计算页。
- ④ **页签**：打开过的页面都留在这里，切换时保留筛选、排序和滚动位置。要重新查询，点“⟳ 刷新”。

“成本报表”不跟随顶栏所选的运行，取数规则见第 10 章。

## 1.4 表格操作

所有表格的用法相同：

| 操作 | 方法 |
|---|---|
| 查看明细 | 双击一行，明细在右侧打开，可继续双击往下钻取 |
| 筛选 | 用工具条上的筛选框，或点列头的 ▾ 按列筛选 |

| 复制到 Excel | 点“复制”，然后粘贴到 Excel |
| 导出 | 点“导出 Excel” |
| 全屏 | 点“⛶ 全屏”，按 Esc 退出 |

表格最多加载 2000 行。行数超出时，用“导出全部 Excel”取得完整数据。

# 第 2 章 月结总览

## 2.1 流程

![月结流程](diagram:flow)

只做检查和正式计算都可以反复执行。在生成凭单之前，发现问题就修改 B1 数据，然后重新计算。

## 2.2 账期状态

每个账期有一个状态，显示在“发起计算”页的账期旁边。

![账期状态](diagram:period)

| 状态 | 含义 | 能否正式计算 |
|---|---|---|
| 未计算 | 本账期还没有成功的正式计算 | 可以 |
| 已计算 | 已有正式计算结果，可反复重算 | 可以 |
| 已生成凭单 | 凭单已生成 | 不可以，要先撤销凭单 |
| 已锁定 | B1 中账期已锁定 | 不可以 |

> **注意**：账期要按顺序结账。下一账期的期初取自上一账期的结果，所以上一账期重新计算后，下一账期也要重新计算。

# 第 3 章 B1 端准备

**负责人**：各业务部门、应付会计、总账会计、关键用户。**时间**：月末单据截止后。

## 3.1 单据和凭证

| 确认事项 | 说明 |
|---|---|
| 库存和生产单据 | 采购收退货、销售交退货、领料、完工入库、库存转储、其他收发货已录完 |
| 形态转换 | 收发两张单据在同一个月，并且一对一配对，不能跨月 |
| 委外加工费 | 本月入库的加工费本月暂估，收货与对应的生产入库在同一账期 |
| 生产订单 | 该关闭的订单已关闭，工单类型不为空 |
| 费用 | 本月费用凭证已过账，成本中心填写正确 |
| 应付发票 | 本月发票已录入，发票差额会计入物料成本 |

计价范围以内的仓库与范围以外的仓库之间不能做库存转储，计算前检查会阻断。

## 3.2 工时

在 B1“生产工时”单据中录入本账期的单位工时。没有单位工时的产品分不到制造费用和人工，计算前检查会阻断。

【待提供：B1 截图 生产工时单据】

不必一次判断哪些产品缺工时。先执行第 4 章的“只做检查”，“工时维护”页会列出清单和参考工时。

## 3.3 费用池和计算参数

费用池和计算参数只在变化时需要维护，在 B1 中修改：

- 费用池：主数据“费用池”（`@MTC_CA_POOL`），维护费用池、所含成本中心和分摊范围。
- 计算参数：表格“计算参数”（`@MTC_CA_PARAM`），一行表示一个参数在一段账期内的取值。

【待提供：B1 截图 费用池主数据、计算参数表格】

改完后在执行台打开“B1 维护数据”，到“费用池”或“计算参数”页签，点“从 B1 拉取”和“检查 B1 配置”。每次计算开始时系统也会自动读取 B1 的配置。

![计算参数总览](shot:b1cfg)

> **注意**：已设置锁定的参数行不能修改或删除。缺少某账期适用取值的参数，会在计算前检查中阻断。

# 第 4 章 只做计算前检查

**负责人**：成本会计（操作权限）。**目的**：在正式计算之前发现数据问题。这一步不计算，也不影响已有结果，可以反复执行。

## 4.1 执行检查

1. 打开左侧菜单“发起计算”。
2. 在 ① 选择账期，确认账期旁边显示的状态。
3. 在 ② 选择“正式”。
4. 确认 ③ 操作人。
5. 点 ④ “只做计算前检查”。

![发起计算页面](shot:run)

完成后自动跳到“校验”页。

## 4.2 查看结果

![校验页面](shot:checks_pre)

运行状态是“检查通过”时进入第 5 章；是“检查阻断”时，表示存在阻断项，必须处理。

| 结果类型 | 处理方式 |
|---|---|
| 阻断 | 必须处理。不处理不能完成计算 |
| 警告 | 不影响计算。逐条查看，确认业务上合理 |

双击校验行查看明细，再双击明细行，可以看到对应物料、单据或订单的当月交易。

## 4.3 常见阻断项

| 问题 | 处理 |
|---|---|
| 缺工时 | 见 4.4 |
| 物料缺少价格来源 | 见 4.5 |
| 形态转换跨月或不是一对一 | 在 B1 更正单据 |
| 工单类型为空 | 在 B1 补填订单的工单类型 |
| 单据不能识别交易类型 | 在 B1 补填业务类型 |
| 计价与非计价仓库之间转储 | 在 B1 更正单据 |
| 计算参数缺少本账期的值 | 在 B1 补参数行，见 3.3 |

## 4.4 工时维护

打开“工时维护”页，这里按产品列出需要补录工时的清单，并给出以前账期的参考工时。

![工时维护页面](shot:hrsneed)

可以用两种方式补录：

- **生成 B1 单据**：点“生成 B1 单据”，核对确认窗口中的写入内容，输入本人 B1 密码。系统追加到本账期工时单，没有时新建一张。已有非 0 的值不会被覆盖，没有参考工时的产品填 0，需要到 B1 改成实际值。
- **手工录入**：点“复制 B1 录入格式”，粘贴后在 B1 录入。

> **注意**：参考工时只供参考，请核对后再使用。

录好后重新执行“只做计算前检查”。

## 4.5 期初价维护

有些物料本期有出库、盘盈、其他入库或无原单退货，但计算前没有任何价格来源。这些物料列在“期初价维护”页。

![期初价维护页面](shot:qcp)

双击一行，可以看到是哪些单据行需要这个价格。系统按以前账期的单价或最近采购价给出建议价，这个价格同样只供参考。补录方式与工时相同，点“生成 B1 单据”或“复制 B1 录入格式”。录好后重新检查，已录入的物料不再出现在清单中。

# 第 5 章 正式计算

**负责人**：成本主管（管理权限）。**前提**：计算前检查没有阻断项。

## 5.1 发起计算

1. 打开“发起计算”，选择账期，类型选“正式”。
2. 点“开始计算”。
3. 在确认窗口核对账套和账期，完整输入账套名，点“确认执行”。

![正式计算确认窗口](shot:run_confirm)

> **注意**：正式计算会覆盖该账期上一次的正式结果。同一时间只能有一个计算在运行，包括其他公司的计算。

## 5.2 查看进度

计算在服务器后台运行，可以关闭网页，稍后再打开。进度显示在“步骤”页，顶栏也有进度标签。

![步骤页面](shot:steps)

“计算过程”页以示意图展示同一次运行，点节点可查看这一步做了什么。

![计算过程页面](shot:flow)

## 5.3 运行结果

| 状态 | 含义 | 下一步 |
|---|---|---|
| 完成 | 计算成功 | 进入第 6 章 |
| 检查阻断 | 计算前检查不通过，没有计算 | 回到第 4 章 |
| 未收敛 | 迭代达到上限，单价仍在变化 | 见第 11 章 |
| 失败 | 运行出错 | 见第 11 章 |

运行没有成功时，步骤上方的红框显示完整报错。点“复制报错”，可以把内容发给系统管理员。

# 第 6 章 计算后复核

**负责人**：成本会计。

## 6.1 计算后校验

打开“校验”页，查看计算后校验。这些校验检查数量是否与 B1 一致、收发存是否平衡、费用是否分摊完、订单是否勾稽、凭证是否借贷平衡等。

![计算后校验](shot:checks_post)

| 结果类型 | 处理方式 |
|---|---|
| 不通过（阻断） | 查明原因。修改数据后重新计算，确属合理的由管理权限在生成凭单时确认 |
| 警告 | 查看原因，例如费用波动、入库 0 成本 |

## 6.2 业务复核

建议每月按以下顺序抽查：

| 页面 | 看什么 |
|---|---|
| 物料单价 | 单价明显异常的物料，与上期比较 |
| 收发存汇总 | 按物料组看期初、入库、出库、期末是否合理 |
| 订单成本 | 单位成本、料工费构成，异常订单双击查看构成 |
| 在产品 | 长期未完工或金额异常的订单 |
| 费用归集、费用分摊 | 各费用池金额是否完整，是否有未分摊的费用 |
| 工时分摊 | 哪些产品没有分到费用及其原因 |

![物料单价](shot:items)

![收发存汇总](shot:inv)

![订单成本](shot:orders)

![费用分摊](shot:pool)

单价有疑问时，用“成本追溯”从物料或订单出发，逐层展开料工费来源，一直追到采购件。

![成本追溯](shot:trace)

# 第 7 章 财务对账

**负责人**：成本会计、总账会计。

## 7.1 财务对账

1. 打开“财务对账”。
2. 点“对账（按当前总账计算）”。

![财务对账](shot:recon)

每个对账项分期初、本期、期末列示业务、财务和差额。

- 财务本期 = 本期总账分录 + 本期未清凭单 + 本次计算底稿中尚未过账的凭证。因此凭单过账之前就可以对账。
- 校验默认按本期差额判断。
- 差额 0.01 也算差异。发出商品的小额尾差由系统按参数上限自动结转。

双击一行查看差额构成。过账或改动总账后，点“重新对账”。

## 7.2 科目余额表

“科目余额表”列出成本相关科目的期初、本期借贷、期末和未过账金额。点科目可看明细账，点分录可看整张凭证或来源。

![科目余额表](shot:tb)

## 7.3 应付暂估和发出商品

| 页面 | 核对内容 |
|---|---|
| 应付暂估 | 截至期末未开票的收货金额，按科目、供应商与总账核对 |
| 暂估凭证 PUR | 逐单据、逐科目核对系统凭证与暂估凭证 |
| 发出商品 | 本期发出、开票和未开票计提的情况 |

![应付暂估](shot:ap)

![发出商品](shot:goods)

未开票发货的计提凭证 AR03、AR04 在下月初自动冲销，所以发出商品科目每月期末余额为 0。

# 第 8 章 调整后重算

只有发现需要调整时才做这一章。所有调整都要在生成凭单之前完成，调整后重新计算。

## 8.1 库存重估

应付发票差额可能使结存金额变成负数，或使单价明显失真。“库存重估”页列出两类物料：

- 结存数量大于 0，但金额小于等于 0。
- 本期发票、贷项差额使加权价偏离较大（默认 10%）。

![库存重估](shot:reval)

1. 勾选要处理的物料，确认或修改目标单价。不勾选的物料不生成。
2. 查看调整金额，点“生成重估单”。
3. 重新计算。

> **注意**：重估金额的对方进入制造费用池，会影响其他产品的分摊，所以生成后必须重新计算。要撤销时，先在 B1 取消这张重估单，再重新计算。

在 B1 手工建的重估单同样生效。

## 8.2 历史委外差异

上线前已关闭、差异留在委外加工物资科目上的委外订单，按整张订单选择账期转出。这项工作只在清理历史差异时使用，需要管理权限，在“历史委外差异”页操作。

![历史委外差异](shot:wwhist)

## 8.3 模拟计算

想先看某项调整的影响，可以用模拟计算：在“模拟场景”页建立假设，发起计算时类型选“模拟”。模拟结果单独保存，不影响正式结果。

# 第 9 章 生成凭单

**负责人**：财务主管（管理权限）。**前提**：校验和对账已完成。

## 9.1 生成

打开“生成凭单”，选择账期。

![生成凭单](shot:jv)

1. 查看计划。凭单取本账期最近一次成功的正式运行，每个凭证代码一行，显示借贷金额和状态。本期 B1 已有同一凭证代码的凭证或未清凭单时自动排除。
2. 有未通过的校验项时，先处理并重新计算；确属合理的，点“确认后仍生成”，写明理由。确认只对这次运行有效。
3. 勾选凭证代码，点“生成凭单”。
4. 输入账套名和本人 B1 密码确认。密码不保存，凭单以本人账号在 B1 中创建。

全部成功后，账期状态变为“已生成凭单”，不能再正式计算。

部分失败时，已生成的保留。可以重试其余代码；确定不再生成时，点“不再生成其余代码，标记为已生成凭单”；也可以撤销后重来。

## 9.2 在 B1 过账

在 B1“财务 → 日记账凭单”中审核并过账。

【待提供：B1 截图 日记账凭单列表】

过账后回到“财务对账”，点“重新对账”，确认总账与业务一致。

# 第 10 章 结账收尾

## 10.1 成本报表

打开“成本报表”，选择报表，填写条件，点“查询”。

![成本报表](shot:rpt)

| 取数规则 | 说明 |
|---|---|
| 已生成凭单的账期 | 取凭单所用的那次运行 |
| 其他账期 | 取最近一次成功的正式运行 |

结果上方写明取的是哪次运行。B1 查询管理器中可以打开同样的报表。

## 10.2 归档

打开“计算说明”，这里汇总了本次运行的步骤、校验、费用和凭证。点“下载 HTML”保存。

![计算说明](shot:report)

建议每月归档：计算说明、收发存汇总、订单成本、财务对账结果。

## 10.3 锁定账期

确认无误后，由财务主管在 B1 中锁定账期。锁定后执行台的账期状态显示为“已锁定”。

# 第 11 章 异常处理

## 11.1 运行失败

1. 打开“步骤”页，查看红框中的报错和出错步骤。
2. 点“复制报错”，发给系统管理员。
3. 修复后重新发起计算。上一次成功运行的结果仍然保留。

## 11.2 迭代未收敛

未收敛表示计算达到迭代上限时单价还在变化。常见原因是物料之间存在循环，例如返工或半成品互相领用。

1. 在“步骤”页查看迭代过程，看单价变化是否在减小。
2. 把报错发给系统管理员，由其定位变化最大的物料。
3. 处理后重新计算。

未收敛的运行不会写入正式结果，本账期之前成功的运行仍然保留。生成凭单取最近一次成功的正式运行，所以在问题解决之前不要生成凭单。

## 11.3 生成凭单后发现问题（凭单未过账）

1. 在 B1“财务 → 日记账凭单”中删除这些凭单。
2. 在执行台“生成凭单”页点“撤销凭单”并确认。账期回到“已计算”。
3. 修改数据，重新计算，走完校验和对账。
4. 重新生成凭单。

## 11.4 凭单已过账后发现问题

1. 在 B1 冲销已过账的凭证。**冲销日期必须选在同一账期内。**
2. 在 B1 删除其余未过账的凭单。
3. 在执行台点“撤销凭单”。
4. 重新计算，再次生成凭单。

> **注意**：冲销日期落到下一账期时，本账期总账仍含原金额，对账和后续计算都会受影响。这种情况不要继续操作，先联系系统管理员核查。

## 11.5 账期结完后又补了单据

- 往已生成凭单的账期补重估单时，之后的计算前检查会报出警告。取消后改到未生成凭单的账期重做，或撤销凭单后重新计算。
- 毛利走势的“月结固定”口径会报出结账后补单的行数。

## 11.6 常见问题

| 现象 | 原因和处理 |
|---|---|
| 登录提示没有权限 | B1 用户主数据的权限字段为空，找管理员开通 |
| “开始计算”是灰色的 | 账期已生成凭单或已锁定、正有计算在运行，或者没有管理权限（正式计算需要管理权限，操作权限可以只做检查和模拟），页面上写有原因 |
| 页面提示这次运行没有结果 | 所选运行是检查或被阻断的运行，在顶栏换一次成功的运行 |
| 改了 B1 配置后页面没变 | 点“从 B1 拉取”，或重新计算 |
| 生成凭单按钮不可用 | 需要管理权限，并且要用账号登录的服务器地址 |

# 附录 术语

| 术语 | 含义 |
|---|---|
| 运行 | 对某个账期的一次计算或检查，有唯一的运行号 |
| 正式 / 模拟 | 正式结果用于凭单和报表；模拟结果只用于分析 |
| 计算前检查 | 计算之前检查数据是否满足条件 |
| 阻断 / 警告 | 阻断必须处理；警告需要查看，不影响继续 |
| 费用池 | 归集费用并按工时分摊给产品的单位 |
| 期初价 | 没有其他价格来源时，在 B1 维护的物料单价 |
| 在产品 | 生产订单已投入、尚未完工转出的成本 |
| 关单差异 | 订单关闭时留下的在产品余额 |
| 发出商品 | 已发货未开票的销售成本 |
| 应付暂估 | 已收货未开票的采购金额 |
| 库存重估 | 调整物料单价的单据 |
| 迭代 / 收敛 | 费用和单价相互影响，要反复计算，直到单价不再变化 |
