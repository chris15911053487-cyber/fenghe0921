# 第 1 章 维护什么、在哪里维护

成本核算的配置都在 B1 中维护，执行台只读取、不修改。每次检查或计算开始时，系统自动从 B1 读取最新配置。

| 配置 | B1 中的位置 | 什么时候改 |
|---|---|---|
| 执行台权限 | 用户主数据的用户定义字段“成本执行台权限” | 新增或调整用户时 |
| 费用池 | 主数据“费用池”（`@MTC_CA_POOL`） | 车间、成本中心、产品范围变化时 |
| 成本中心归池 | 成本中心主数据的“成本计入类型”（`U_CalType`） | 新增成本中心时 |
| 计算参数 | 表格“成本计算参数”（`@MTC_CA_PARAM`） | 科目、凭证代码、阈值、业务口径变化时 |
| 单位工时 | 生产工时单据（`@MTC_COST_TIME`） | 每月 |
| 期初成本价 | 期初成本价单据（`@MTC_COST_QCPRICE`） | 计算前检查提示时 |
| 仓库是否计价 | 仓库主数据 `U_IsCost` | 新增仓库时 |
| 交易类型、业务类型 | `@MTC_COST_IOTYPE`、`@U_CIOTRN` | 新增业务类型时 |

改完后在执行台“B1 维护数据”页点“从 B1 拉取”和“检查 B1 配置”，确认没有问题。

# 第 2 章 权限

执行台用 B1 账号登录，权限取用户主数据上的用户定义字段：

| 取值 | 权限 | 可以做什么 |
|---|---|---|
| R | 查看 | 查看运行结果、校验、对账和报表 |
| O | 操作 | 另可只做检查、模拟计算、维护模拟场景，生成期初价、工时和库存重估单据 |
| A | 管理 | 另可正式计算、期初承接、生成和撤销凭单、确认校验阻断项 |
| 空 | 无 | 不能登录 |

在 B1“管理 → 设置 → 常规 → 用户”中打开用户，在用户定义字段栏（菜单“视图 → 用户定义字段”）选择权限，用户下次登录执行台时生效。同一个人在不同公司可以有不同的权限。

字段由系统管理员在部署时添加，方法见《部署与运维手册》。

# 第 3 章 费用池

费用池决定费用归到哪里、分摊给哪些产品。

## 3.1 表头

| 字段 | 填法 |
|---|---|
| 代码、名称 | 费用池代码和名称 |
| 默认池 | 没有对应成本中心的费用进入默认池，所有费用池中**正好一个**填 Y |
| 关单差异池 | 关单差异进入这个池，**正好一个**填 Y |
| 说明 | 备注 |

## 3.2 成本中心（子表）

列出归入本池的成本中心。成本中心可以直接填代码，也可以填成本计入类型（见 3.4）。默认池可以不填。

## 3.3 分摊范围（子表）

| 字段 | 填法 |
|---|---|
| 匹配方式 | 按物料组（GRP）或按车间类别（GRPTYPE） |
| 匹配值 | 物料组代码或车间类别 |
| 订单类型 | 参与分摊的订单类型，多个用逗号分隔 |
| 起始 / 截止账期 | 留空表示全部账期 |

同一个产品同一时期只能属于一个费用池。

## 3.4 成本中心归池

成本中心主数据上的“成本计入类型”字段（`U_CalType`）填写费用池子表中登记的值，该成本中心的费用就进入那个池；不填则进入默认池。以后新增同类成本中心，只要填这个字段，不用改费用池。

在成本中心子表中单独登记了代码的成本中心，以单独登记为准。

# 第 4 章 计算参数

计算参数表一行表示一个参数在一段账期内的取值。

| 字段 | 填法 |
|---|---|
| 代码 | 参数代码，区分大小写。同一参数的第二段起写成“参数代码@起始账期” |
| 名称、分类 | 参数的中文名和分类，照抄 |
| 起始 / 截止账期 | 留空表示全部账期 |
| 取值 | 列表用逗号分隔，前后不加逗号；数字只填数字，不带单位或 % |

## 4.1 修改参数

**不要直接改原来那一行的取值**，否则重算以前的账期时会用上新值。正确做法：

1. 把原来那一行的截止账期填成上一期。
2. 新增一行，代码填“参数代码@新账期”，起始账期填新账期，填新取值。

同一参数的账期段不能重叠，保存时会校验。

## 4.2 锁定

参数行的“锁定”字段为 Y 时，保存时不能修改取值，也不能删除。锁定和解锁的权限由 B1 权限控制。

## 4.3 缺参数

系统登记的参数在 B1 中没有适用于本账期的行时，计算前检查会阻断（PRE-28），需要补上。在 B1 中删除一行参数不会恢复默认值。

## 4.4 系统参数

“计算控制”分类中的收敛标准、最大迭代轮数、起始账期、承接账期等是系统参数，以及“成本模块生成的凭证代码”，录入后不要改。需要调整时先联系成本核算实施人员。

## 4.5 参数清单

以下清单从系统实时读取，显示当前账期适用的取值和来源（B1 或系统默认值）。在执行台“B1 维护数据 → 计算参数”页可以看到更完整的状态和锁定情况。

# 第 5 章 工时和期初价

## 5.1 单位工时

在 B1 生产工时单据中录入本账期各产品的单位工时。

- 同一产品同一账期只能有一个单位工时。
- 本期有入库、在费用池分摊范围内的产品必须有单位工时，否则计算前检查阻断。
- 执行台“工时维护”页列出缺工时的产品和参考工时，可以直接生成 B1 单据，也可以复制后手工录入。见《成本月结操作手册》第 4 章。

## 5.2 期初成本价

物料本期有出库等需要单价的变动，但计算前没有任何价格来源时，要在期初成本价单据中维护单价。执行台“期初价维护”页列出这些物料、需要它的单据行和建议价。

期初价只作为没有其他价格来源时的初始价或兜底价，有采购、完工入库或期初结存时以实际成本为准。

# 第 6 章 凭证代码

成本模块生成的凭证代码（MR01、PP05、DN03、PUR1 等）必须在 B1 凭证代码（交易代码）中存在。新增凭证代码时，同时把它加进计算参数“成本模块生成的凭证代码”。

使用历史委外差异转出时，要先在 B1 建凭证代码 JZ05，加进上述参数，并且**不要**加进“计入费用池的凭证代码”参数（否则转出金额会被重复计入费用池）。计算前检查 PRE-30 会核对这些配置。
