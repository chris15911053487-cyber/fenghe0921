# 第 1 章 校验的种类

| 阶段 | 编号 | 什么时候执行 | 结果 |
|---|---|---|---|
| 计算前检查 | PRE-xx | 只做检查、正式计算、模拟计算开始时 | 阻断项不通过时不计算；警告不影响计算 |
| 计算后校验 | POST-xx | 计算完成后 | 不通过的阻断项要处理，或在生成凭单时由管理权限确认 |
| 新旧比对 | CMP-xx | 计算完成后 | 只用于并行期核对，不影响凭单 |

“校验”页列出本次运行的全部校验：结果、是否阻断、问题行数和说明。双击一行看明细；明细是物料、单据或订单时，再双击可以看对应的当月交易。

## 1.1 阻断和警告

- **阻断**：数据不满足计算条件，或者结果不平。计算前检查有阻断项时，运行状态为“检查阻断”，不计算。
- **警告**：需要人看一眼、确认业务上合理的情况，不影响计算和生成凭单。
- 哪些计算后校验只警告，由参数决定（见《B1 配置维护手册》）。

## 1.2 确认阻断项

计算后校验不通过时不能生成凭单。确属合理的（例如已知的历史差异），由管理权限在“生成凭单”页逐项点“确认后仍生成”并写明理由。

- 确认只对这一次运行有效，重新计算后要重新确认。
- 确认记录保留在系统中，可以在“生成凭单”页看到确认人、时间和理由。

# 第 2 章 计算前检查的处理

## 2.1 单据问题

| 编号 | 问题 | 处理 |
|---|---|---|
| PRE-03 | 形态转换跨月、不是一对一、配对信息不完整 | 在 B1 更正收发两张单据，使其同月、一对一 |
| PRE-05 | 库存变动识别不了交易类型 | 补填其他收发货的业务类型；应收贷项凭证不能直接退货入库 |
| PRE-06 | 领料或入库指向的订单不存在 | 核对单据上关联的订单号 |
| PRE-07 | 计价仓库与非计价仓库之间转储 | 取消该转储，改为计价仓库之间的转储 |
| PRE-10 | 已关闭或已取消的订单本期仍有出入库 | 核对单据是否挂错订单 |
| PRE-11 | 订单已关闭但没有关单日期 | 在 B1 核对订单状态 |
| PRE-24 | 订单的工单类型为空 | 在 B1 补填订单的工单类型 |
| PRE-25 | 其他收发货的科目与库存交易事务配置不一致 | 更正单据科目，或补库存交易事务配置 |
| PRE-26 | 应收发票不基于交货、应收贷项不基于退货 | 库存物料必须先交货再开票；改为基于交货 / 退货开票 |
| PRE-27 | 销售单据没有客户类型 | 补销售订单类型对应的客户类型 |

## 2.2 工时和费用池

| 编号 | 问题 | 处理 |
|---|---|---|
| PRE-13 | 同一产品同一账期有多个不同的单位工时 | 在 B1 工时单中只保留一个 |
| PRE-14 | 应分摊费用的订单，产品没有单位工时 | 在“工时维护”页补录，见《成本月结操作手册》第 4 章 |
| PRE-17 | 有入库的产品不在任何费用池的分摊范围 | 核对物料组或车间类别，或调整费用池分摊范围（警告） |
| PRE-18 | 费用池配置无效 | 默认池、关单差异池必须正好各一个；同一产品只能属于一个池 |
| PRE-19 | 订单本期净入库为负 | 这类订单不分摊制造费用和人工，核对完工退回（警告） |

## 2.3 价格和期初

| 编号 | 问题 | 处理 |
|---|---|---|
| PRE-02 | 物料层级不完整（BOM 子件缺失或循环引用） | 更正 BOM |
| PRE-04 | 销售退货没有原交货 | 允许发生；有期初维护价按维护价，没有按加权价（警告） |
| PRE-16 | 没有期初 | 上一账期先完成正式计算；第一个账期先做期初承接 |
| PRE-23 | 物料需要维护期初价 | 在“期初价维护”页补录（警告，但不补会导致 0 成本） |

## 2.4 配置和参数

| 编号 | 问题 | 处理 |
|---|---|---|
| PRE-01 | 账期已锁定 | 已锁定的账期不能正式计算，可以做模拟 |
| PRE-28 | B1 计算参数缺少本账期的值 | 在 B1 计算参数表补上适用本账期的行 |
| PRE-30 | 历史委外差异转出所需的凭证代码和参数没有配置 | 按《B1 配置维护手册》补配置 |

## 2.5 只警告的检查

| 编号 | 提示 | 看什么 |
|---|---|---|
| PRE-08 | 非计价仓库中有生产或采购 | 这些行不计成本，确认仓库设置是否正确 |
| PRE-09 | 试打订单用了不允许的领料类型 | 核对领料业务类型 |
| PRE-12 | 委外加工费找不到订单 | 这笔加工费不会进入任何订单，核对加工费收货的关联 |
| PRE-15 | 制造费用可能重复计入 | 同一张其他出入库单既有费用凭证、又作为公摊材料 |
| PRE-20 | 发票不基于收货 | 应付发票应基于收货或退货 |
| PRE-21 | 委外发票差额找不到产品 | 补发票行上的产品 |
| PRE-22 | 暂估变动没有库存记录 | 核对收货是否进了计价仓库 |
| PRE-29 | 已生成凭单的账期有新建的重估单 | 取消后改到未生成凭单的账期，或撤销凭单后重新计算 |
| PRE-31 | 委外加工费与入库不在同一账期 | 业务要求本月入库本月暂估，核对加工费收货日期 |

# 第 3 章 计算后校验的处理

| 编号 | 内容 | 不通过时 |
|---|---|---|
| POST-01 | 期末数量 = B1 库存数量 | 计价仓库口径与 B1 不一致，联系系统管理员 |
| POST-02 | 收发存四项平衡 | 联系系统管理员 |
| POST-03 | 费用池全部分摊 | 有未分摊的费用：核对分摊范围和工时 |
| POST-04 | 订单结转勾稽、关单订单在产品为 0 | 联系系统管理员 |
| POST-05 | 形态转换、退货、取消单按原单金额 | 明细列出找不到原单、按加权价兜底的行 |
| POST-06 | 委外加工物资对账 | 双击看差额构成；常见原因是手工调整或加工费没关联订单 |
| POST-07 | 物料异常：负库存、兜底价、无价、0 成本入库 | 补期初价或核对单据后重新计算 |
| POST-08 | 凭证借贷平衡、科目齐全 | 补科目配置后重新计算 |
| POST-09 | 存货科目总账 = 业务 | 见 4.1 |
| POST-10 | 发出商品对账 | 小额尾差按参数自动结转；超过的核对交货和开票 |
| POST-11 | 应付暂估对账 | 按供应商看差额，核对暂估凭证 |
| POST-12 | 销售成本取价 | 找不到交货成本或客户类型的行 |
| POST-13 | 生产成本对账 | 双击看差额构成 |
| POST-14 | 物料成本异常（尾差、单价波动） | 逐项看过即可（警告） |
| POST-15 | 暂估凭证 PUR 逐单据勾稽 | 在“暂估凭证 PUR”页查看（警告） |
| POST-16 | 制造费用、人工波动 | 与前几个月的中位数相比偏离较大，确认费用是否完整（警告） |
| POST-17 | 按加权价入库的物料单价为 0 | 补期初价或核对来源（警告） |
| POST-18 | 领料完整性：收发存明细的订单领料 = 订单本期领料；生产领料、完工入库没挂订单的行 | 核对单据上的订单号，改好后重新计算（警告） |
| POST-19 | 本期有完工但没有材料 | 核对是否漏做领料或领料挂错订单（警告） |
| POST-20 | 单耗偏离：订单累计领料与按订单用料计划应领相差较大 | 核对超领、少领或替代料（警告） |

# 第 4 章 对账差异的排查

## 4.1 存货科目有差额

1. 在“财务对账”双击该科目，看差额落在期初、本期还是期末。
2. 期初有差额：上一账期没有对平，或上一账期结账后又改了总账。
3. 本期有差额：看“财务本期”的分录构成，找不是成本模块生成的分录（手工凭证、其他模块的凭证）。
4. 在“科目余额表”点该科目看明细账，点分录看整张凭证。

## 4.2 应付暂估有差额

1. 在“财务对账”展开应付暂估，按供应商看差额。
2. 在“应付暂估”页看该供应商截至期末未开票的收货。
3. 在“暂估凭证 PUR”页逐单据核对系统凭证和暂估凭证。

## 4.3 发出商品有差额

发出商品每月期末应为 0。差额通常来自：上月计提的冲销没有生成、交货或开票的取消单、没有客户类型的销售单据。

# 第 5 章 运行出错和未收敛

| 现象 | 处理 |
|---|---|
| 运行失败 | 在“步骤”页红框中点“复制报错”，发给系统管理员；上一次成功的结果仍然保留 |
| 迭代未收敛 | 迭代达到上限时单价还在变化。看“步骤”页的迭代过程，把报错发给系统管理员，由其定位单价变化最大的物料 |
| 计算前检查阻断 | 按第 2 章处理后重新检查 |

未收敛或失败的运行不写结果，本账期之前成功的运行仍然保留。生成凭单取最近一次成功的正式运行，问题解决之前不要生成凭单。
