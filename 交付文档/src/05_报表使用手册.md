# 第 1 章 在哪里查

成本报表有两个入口，调用的是同一批报表程序，口径只有一套：

| 入口 | 方法 |
|---|---|
| 成本执行台 | 左侧菜单“成本报表”分组。“成本报表”页可以选任意一张；R22 生产成本走势、R23 销售毛利走势另有单独的菜单，带图表 |
| B1 查询管理器 | B1“工具 → 查询 → 查询管理器”，分类“成本报表（新）”。执行时依次弹出参数框 |

在执行台“成本报表”页选中报表后点“在 SAP 中打开”，可以看到 B1 查询语句和参数顺序。

# 第 2 章 取数规则

报表不跟随顶栏所选的运行，按账期自动选择：

| 账期 | 取哪次运行 |
|---|---|
| 已生成凭单 | 生成凭单所用的那次运行 |
| 已计算、未生成凭单 | 最近一次成功的正式运行 |
| 新系统上线前 | 旧系统结果回填的历史数据 |
| 没有计算过 | 没有数据 |

查询结果上方写明每个账期取的是哪次运行、什么时候算的。R00“成本报表运行状态”列出全部账期的取数情况。

上线前的历史数据来自旧系统，料工费按旧系统完工成本的比例拆分，是估算值；部分报表在历史账期只返回提示。

# 第 3 章 条件怎么填

| 条件类型 | 填法 |
|---|---|
| 账期 | 下拉选择，有的报表可以选起止账期 |
| 物料、订单、物料组等代码 | 留空 = 全部；按开头匹配；多个用逗号分隔；前面加“=”表示精确匹配 |
| 下拉选项 | 按提示选择，例如汇总 / 明细、按产品 / 按订单 |
| 是 / 否 | 勾选或选择 |

执行台中改了条件不会自动查询，点“查询”或在输入框中按 Enter 才查。点“恢复默认条件”回到默认值。条件记在本机浏览器，下次打开仍在。

# 第 4 章 查看和导出

- 表格的筛选、排序、复制、导出 Excel 与执行台其他表格相同，见《成本月结操作手册》第 1 章。
- 带“双击一行看明细”提示的报表，可以双击钻取到下一层报表，条件自动带过去。
- 行数超过 2000 时只加载前 2000 行，底部合计标为“已加载 N 行合计”；用“导出全部 Excel”取得完整数据。

# 第 5 章 勾稽关系

几张报表之间有固定的勾稽关系，可以用来交叉核对：

| 关系 | 说明 |
|---|---|
| R01 完工转出 = R02 完工成本 = R03 生产入库 | 产品成本计算单、完工产品成本汇总、收发存汇总一致 |
| R01 本级分摊 = R06 已分配 | 费用分配表与成本计算单一致，R06 未分配应为 0 |
| R03 期末合计 = R09 存货业务端 | 收发存与财务对账一致 |
| R07 期末在产品 = 委外加工物资业务端 | 委外加工成本表与财务对账一致 |
| R10 来源明细合计 = 分录合计 | 凭证清单与业务来源一致 |
| R19 期末在产品 = R20 明细合计 | 在产品汇总与明细一致 |

报表程序另有一组自动勾稽，由系统管理员在部署后执行。

# 第 6 章 走势报表

## 6.1 R22 生产成本走势

物料每个月的完工数量、单位成本和料工费构成，月份作为列，适合看连续几个月的趋势。

- 料工费有两种口径：“本级”只算本订单分摊的制造费用和人工，半成品全部算作材料；“成本还原”把半成品中的料工费也拆出来。两种口径合计相同。
- 不同产品的单位成本不能相加，汇总图看的是完工成本和料工费占比。
- 双击产品看单位成本构成和完工订单。

## 6.2 R23 销售毛利走势

物料每个月的收入、成本和毛利，属于业务口径，与凭证是否过账无关。有两种口径：

| 口径 | 含义 | 适用 |
|---|---|---|
| 随时看 | 当月发票 + 当月交货中至今未开票的部分（暂估）。以后开票时，这笔货移到开票的月份，以前月份的数会变 | 日常分析 |
| 月结固定 | 当月发票 + 期末暂估 − 期初暂估，只列已结账账期，数字不再变化 | 给管理层的月报 |

- 样品默认不含，可以勾选包含。
- 没有对应交货的发票或贷项归在“(未归属产品)”。
- “月结固定”口径下，往已结账的账期补单时会报出“结账后补单行数”。
- 表格每行有迷你走势图；勾选最多 6 个物料，在上方对比图中比较；双击行看单品明细。
