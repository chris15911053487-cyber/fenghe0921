# 关于本说明

本说明介绍成本核算的口径：取哪些单据，每类交易怎么定价，订单成本、在产品、费用分摊怎么算，生成哪些凭证，怎样与总账对账。操作步骤见《成本月结操作手册》。

规则编号、校验编号和参数代码以系统登记为准，本说明第 10 章从系统中实时列出。

# 第 1 章 总体原则

| 原则 | 含义 |
|---|---|
| 实际成本、月加权平均 | 物料按月计算加权平均单价，材料、人工、制造、委外四项成本分别计算、分别结转 |
| 截至期末 | 只取过账日期在期末及以前的单据；订单状态、关单日期、未清数量也按截至期末判断，不看单据现在的状态 |
| 一次运行得出结果 | 关单差异、返工、形态转换、期初维护价都在同一次计算中处理，结果与计算次数无关，不需要算两遍 |
| 每个数可追溯 | 每行结果都记录价格来源和规则；单价和订单成本可以逐层追到原单据行 |
| 只读单据 | 计算不修改 B1 单据，结果写入成本模块自己的表 |

计价范围：只计算仓库主数据中标记为“计价”的仓库。计价仓库与非计价仓库之间不能做库存转储。

# 第 2 章 计算流程

![计算流程](diagram:calc)

1. **取快照**：把本账期截至期末的单据、订单、工时、期初价、费用凭证、配置复制成快照，之后的计算只用快照。
2. **计算前检查**：在快照上检查数据是否满足计算条件，有阻断项就停止，不计算。
3. **固定价格**：采购入库、发票差额、库存重估、取消单配对等不随计算变化的金额先定下来。
4. **迭代计算**：每一轮依次计算费用池、分摊到订单、按物料层级从下到上逐级给领料定价、结转订单成本、算出完工入库成本和物料加权单价。
5. **收敛判断**：本轮单价与上一轮相比不再变化，费用池和关单差异也不再变化，就停止迭代。
6. **写结果、校验、生成凭证底稿**：写入物料、订单、在产品、费用分摊等结果，执行计算后校验，生成凭证底稿，与总账对账。

需要迭代，是因为费用和单价相互影响：公摊材料、关单差异进入费用池，费用池分摊又影响产品单价，产品单价再影响领用它的订单。返工单领用和产出同一个物料，也要通过迭代算到一致。

# 第 3 章 各类交易的定价

| 交易 | 定价 |
|---|---|
| 采购入库、采购退货 | 暂估金额：行上填了指定单价的按指定单价；价格已确认的按单价；否则按行金额。基于收货的退货按收货行的暂估单价 |
| 应付发票、贷项 | 发票金额减去冲回的暂估金额，差额计入物料成本；分次开票的最后一次清掉余数 |
| 库存重估 | 重估单上的金额 |
| 生产、返工、委外完工入库 | 订单本期完工成本 ÷ 本期入库数量 × 行数量，尾差挤到数量最大的行 |
| 生产、返工、委外领料 | 子件本期加权单价，四项分别计 |
| 生产退料 | 该订单该材料截至本期的平均领料单价；订单没有领料时按物料加权单价 |
| 销售出库 | 本期加权单价 |
| 销售退货（有原交货） | 原交货行的成本 |
| 销售退货（无原交货） | 期初维护价；没有维护价按本期加权单价 |
| 形态转换转出 | 被转换物料的本期加权单价 |
| 形态转换转入 | 等于配对的转出金额（同月、一对一） |
| 其他出入库、盘点、试打领用 | 物料本期加权单价；记入制造费用科目的部分进入费用池 |
| 取消单 | 原单成本反向 |
| 报废类业务 | 不计价 |

**加权单价** = （期初金额 + 本期计入加权的入库金额）÷（期初数量 + 本期计入加权的入库数量），材料、人工、制造、委外四项分别计算。每条单据行定价时四项分别保留 2 位小数。

**价格来源**：本期有出库、其他入库、盘点或无原单退货的物料，计算前必须有价格来源，即期初结存金额、本期有金额的采购 / 完工 / 形态转换入库，或在 B1 维护的期初价。都没有时，计算前检查会列出，在“期初价维护”页补录。0 金额的采购收货不算价格来源。

**尾差**：物料期末数量为 0、金额不为 0 时，尾差挤进该物料数量最大的出库行。零库存物料的小额尾差在参数上限以内的，由尾差凭证结转。

# 第 4 章 订单成本与在产品

## 4.1 结转公式

按“订单 × 材料”计算，四项成本分别计：

```
累计领料金额 = 截至上期累计 + 本期领料
结转比例     = min(累计入库数量 ÷ 订单计划数量, 1)
本期结转     = 累计领料金额 × 结转比例 − 以前各期已结转
期末在产品   = 累计领料金额 − 累计结转
```

订单本期完工成本 = 各材料本期结转 + 本期分摊的制造费用和人工 + 本期结转的委外加工费。

- 制造费用和人工只分摊给本期有入库的订单，不留在在产品中。
- 订单全部入库后又补领的材料，在本期没有入库可以承接时留在在产品中，关单时转为关单差异。

## 4.2 关单差异

订单截至期末已关闭、关单日期在本期时，剩余在产品转为关单差异，订单在产品清零。关单差异进入指定的费用池，在同一次计算中分摊给本期完工的产品。

## 4.3 返工单

返工单会领用产品 A，加上其他材料和工费后再入库成 A。领用的 A 与产出的 A 是同一个物料，系统用迭代计算：每一轮按上一轮 A 的单价给领料定价，直到 A 的单价不再变化。返工单与普通订单使用同一个结转公式。

## 4.4 形态转换

形态转换用其他出库单发出 B、其他收货单收入 A，不经过生产订单。A 的入库金额等于 B 的出库金额。收发两张单据必须在同一个月、一对一配对，计算前检查会拦截跨月和一对多。

## 4.5 委外订单

委外订单的成本 = 发出材料 + 委外加工费，不分摊制造费用和人工。

- 加工费按加工费收货的暂估金额归集到订单。订单本期有入库时，截至本期归集、尚未结转的加工费全部结转到本期入库；本期没有入库时留在订单上，下次入库时结转；关单时剩余部分转为关单差异。
- 业务上要求本月入库的加工费本月暂估。加工费收货与对应的生产入库不在同一账期时，计算前检查给出警告。

## 4.6 本级与成本还原

订单完工成本中的制造费用和人工有两种看法：

| 口径 | 含义 |
|---|---|
| 本级 | 本期分摊到这张订单的制造费用和人工，加上这张订单自己的委外加工费；半成品的全部成本都算作材料 |
| 成本还原 | 本级部分，加上领用的材料和半成品中所含的制造费用、人工和委外加工费 |

两种口径的合计相同，都等于完工成本。订单成本页和部分报表可以切换口径。

# 第 5 章 费用归集与分摊

## 5.1 费用来源

| 来源 | 内容 |
|---|---|
| 费用凭证 | 本期总账中制造费用科目和人工科目的发生额，只取参数中列出的凭证代码 |
| 公摊材料 | 其他出入库、盘点单中记入制造费用科目的物料成本，每轮按最新单价重算 |
| 库存重估 | 重估单的对方金额；没有关联到订单的委外加工费重估 |
| 关单差异 | 本期关单订单的剩余在产品 |

## 5.2 归入费用池

费用按来源行的成本中心归入费用池。成本中心与费用池的对应关系在 B1 费用池主数据中维护，没有对应关系或没有成本中心的费用进入默认池。关单差异进入指定的“关单差异池”。

## 5.3 分摊

每个费用池按分摊范围（物料组或车间类别、订单类型）分摊给本期有入库的订单：

```
订单权重 = 产品单位工时 × 订单本期入库数量
订单分摊额 = 费用池金额 × 订单权重 ÷ 池内全部订单权重之和
```

- 制造费用和人工用同一个权重，最后一次取整，尾差挤到最大的一行。
- 本期净入库为负的订单不分摊。
- 委外订单不分摊。
- 本期有入库、在分摊范围内、但产品没有单位工时的订单，计算前检查会阻断。同一产品同一账期只能有一个单位工时。
- 某个池本期没有可分摊的订单时，金额记为“未分摊”，计算后校验会报出，不转入下期。

# 第 6 章 期初

- 新系统的第一个账期，物料和订单的期初取自上线前旧系统最后一期的结果（期初承接）。旧系统没有分料工费的部分，按旧系统最近一期完工成本的构成比例拆分。
- 以后各期的期初取上一账期最近一次成功的正式计算结果。所以上一账期重新计算后，本账期也要重新计算。
- 上线前的账期由历史回填生成，供成本报表查询，不参与新账期的计算。

# 第 7 章 凭证

计算生成凭证底稿，每种凭证代码一张，凭证日期为期末日。底稿在执行台“凭证”页查看，确认后由“生成凭单”写入 B1 日记账凭单，在 B1 审核过账。

借贷方向与旧系统相同：每种分录的借方、贷方是固定的，金额反向时（退回多于领用、盘盈、差异为负等）在原方向记红字（负数），不换到另一方；同一科目借贷两边都有时分两行列示，不轧差。冲回 B1 系统凭证（PUR2、PUR3、PUR5）时，在原分录同一方记红字。B1 公司设置要允许负数金额。

| 凭证代码 | 内容 |
|---|---|
| MR01 / MR02 | 库存重估 |
| YF01 / IO01 | 其他出入库、盘点：借行上科目，贷存货 |
| PP01 / WW01 | 生产领料 / 委外发料：借订单在产品科目，贷存货 |
| IO02 | 形态转换：借转入物料存货，贷转出物料存货（同一科目借贷各一行） |
| PP05 | 生产完工入库：借存货，贷生产成本；其中分摊的制造费用、人工贷对应的费用转出科目 |
| WW03 | 委外完工入库：借存货，贷委外加工物资（材料、加工费分别贷） |
| PP04 | 制造费用科目本期发生额转入生产成本：借生产成本-制造费用，贷各制造费用科目 |
| JZ01 / JZ03 | 生产订单 / 委外订单的关单差异：两行都记借方，关单差异科目正数、在产品科目红字 |
| JZ04 | 零库存尾差、发出商品小额尾差：借存货 / 发出商品，贷主营业务成本 |
| JZ05 | 历史委外差异转出（只在清理历史差异时生成）：两行都记借方 |
| DN01 | 销售交货 / 退货转入发出商品 |
| DN02 / DN04 | 样品销售转出（国内 / 国外），含视同销售销项税 |
| DN03 | 本期开票部分由发出商品转入主营业务成本 |
| AR03 / AR04 | 期末未开票交货计提销售成本（国内 / 国外），下月初由 B1 自动冲销 |
| PUR1–PUR5 | 应付暂估：冲掉 B1 标准成本自动生成的收货、退货、发票凭证，按暂估口径重记。PUR1 / PUR4 借存货 / 140802、贷 220202 应付暂估 |

存货科目取物料组的存货科目；委外订单的在产品科目是委外加工物资，其他订单是生产成本。

# 第 8 章 财务对账

财务对账逐项比较业务端（计算结果）与财务端（总账）：

| 对账项 | 业务端 |
|---|---|
| 存货科目 | 物料期末金额，按物料组的存货科目汇总 |
| 生产成本 | 生产、包装、返工订单的在产品 |
| 委外加工物资-材料 | 委外订单的在产品（材料） |
| 委外加工物资-加工费 | 委外订单尚未结转的加工费 |
| 发出商品 | 期末为 0：月末未开票部分全部计提，下月初冲销 |
| 应付暂估 | 截至期末已收货未开票的金额，按供应商 |

**财务端** = 总账已过账分录 + 未清凭单 + 本次凭证底稿中尚未过账的凭证。同一凭证代码已经过账或已在未清凭单中的，不重复计入。因此凭单过账之前就能对账，过账之后重新对账结果不变。

- 期初、本期、期末分开列示业务、财务和差额。默认按本期差额判断。
- 生产成本、委外加工物资-材料、发出商品只比较成本模块生成的凭证；手工调整等其他分录单独列出，不算差异。
- 差额 0.01 也算差异。

# 第 9 章 库存重估与历史委外差异

**库存重估**：发票差额可能使物料结存金额为负，或使单价明显偏离。系统列出结存数量大于 0 但金额小于等于 0、或发票差额使加权价偏离超过参数阈值的物料，给出建议单价。确认后生成 B1 重估单，重估金额的对方进入费用池，重新计算后生效。

**历史委外差异**：上线前已关闭、差异留在委外加工物资科目上的委外订单，可以按整张订单选择账期转出。转出金额进入费用池分摊给当月完工产品，同时生成 JZ05 凭证。
